STAGE 3

継承

「〜の一種」を親子で表す
🎯 ミッション
継承のしくみ（共通部分を親に書き、子が受け継ぐ）と、継承してよいかを is-a で確かめる方法を説明できるようになろう。Dog・Cat・Bird で使えるものを調べ、確認クイズに全問正解すれば合格。
未達成
ねこ博士
犬・猫・鳥は、どれも名前を持ち、食べて、眠る。この共通部分を、それぞれのクラスに書くとコピーになってしまう。そこで、共通部分だけを書いた親クラス Animal を作り、Dog・Cat・Bird はそれを受け継ぐことにする。これを継承と呼ぶ。
class Animal {
    String name;
    void eat()   { … }
    void sleep() { … }
}
class Dog extends Animal {   // Dog は Animal を受け継ぐ
    void bark()  { … }       // Dog だけの機能を足す
}
 extends は「広げる」。Dog は Animal に bark() を足して広げたもの。Animal を親クラス（スーパークラス）、Dog を子クラス（サブクラス）と呼ぶ
うさ美
Dog の中には eat() を書いていないのに、new Dog().eat() が使えるんですか？
ねこ博士
使える。メソッドを呼ばれたとき、Java はまず Dog の中を探し、無ければ親の Animal、さらにその親……と上へたどって探す。だから、eat() を直したいときは Animal の1か所を直せば、Dog にも Cat にも Bird にも反映される。
うさ美
STAGE1 のえさの計算も、Animal に1回だけ書いておけば、直すのも1か所で済む。
ねこ博士
そう。親子は何段にも重ねられる。犬と猫は「お乳で子を育てる」哺乳類だから、Animal と Dog のあいだに Mammal（哺乳類）をはさむこともできる。
うさ美
何でも共通部分があれば、継承していいんですか？ たとえば、車にも「名前」と「動く」があるから、Car extends Animal でもいいような……。
ねこ博士
いい質問だね。継承してよいかの目安は、「子は親の一種である」と自然に言えるかどうかだ。英語で "is a"（〜は…の一種だ）と言えるかを確かめるので、is-a の関係と呼ぶ。
うさ美
「犬は動物の一種だ」は自然。「車は動物の一種だ」は変です。だから、車は Animal を継承してはいけない。
ねこ博士
そう。is-a が成り立たないのに、共通のメソッドがあるからと継承すると、あとで困る。動物用に Animal に足した機能（たとえば「えさをやる」）が、車にも勝手に付いてきてしまうからね。共通の機能を別の形で分け合う方法は、STAGE6 と STAGE10 で見よう。
継承：共通部分を親クラスに1回書き、子クラスが extends で受け継ぐ。子は機能を足せる メソッドの探し方：自分のクラス → 親 → その親……の順にたどる 継承してよいか：「子は親の一種」（is-a）と自然に言えるか。Java では親クラスは1つだけ
うさ美
「親クラスは1つだけ」というのは？
ねこ博士
Java では、extends の後ろに書ける親は1つだけ、と決まっている。複数の親を持てる言語もあるけれど、両方の親に同じ名前のメソッドがあったとき、どちらを使うかがややこしくなる。この話も STAGE6 でまた出てくる。次は、親クラスで「中身は子どもに任せる」書き方だ。

確認クイズ

Q1. Dog extends Animal のとき、Dog のインスタンスで eat() を呼ぶと、Java はどう探す？

正解！ 自分のクラスから親へ向かって上にたどる。Dog に書いていなくても、Animal の eat() が使える。

Q2. 継承してよいかを確かめる目安は？

正解！ is-a が成り立たないのに継承すると、親に足した機能が関係ない子にも付いてきてしまう。

Q3. Animal の eat() の中身を直すと、どうなる？

正解！ 子クラスは親の eat() をそのまま使っているので、直すのは1か所でよい。
